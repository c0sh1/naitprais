# Fuentes

## Datos

| Fuente | Qué usamos | Enlace |
|---|---|---|
| ISTAC (Instituto Canario de Estadística) | Viviendas vacacionales por municipio y mes: disponibles, plazas, ocupación, estancia media e ingresos (dataset C00065A_000061). También los ingresos de Canarias de 2025 para calibrar la estacionalidad de los datos simulados | [Catálogo del dataset](https://datos.canarias.es/catalogos/estadisticas/dataset/urn-siemac-org-siemac-metamac-infomodel-statisticalresources-dataset-istac-c00065a_000061) |
| ISTAC, colección de viviendas vacacionales | Series mensuales y anuales por municipios e islas (2019-2026) | [Banco de datos](https://www3.gobiernodecanarias.org/istac/statistical-visualizer/visualizer/collection.html?resourceType=collection&agencyId=ISTAC&resourceId=C00065A_000003) |
| ISTAC, nota de enero de 2026 | Número de viviendas vacacionales en Canarias y reparto por islas | [Nota de prensa](https://www.gobiernodecanarias.org/istac/.content/noticias/estadistica-experimental-vivienda-vacacional-noticia-2026-enero.html) |
| Gobierno de Canarias, datos abiertos | Registro General Turístico: viviendas vacacionales inscritas | [Dataset](https://datos.canarias.es/catalogos/general/dataset/establecimientos-extrahoteleros-de-tipologia-vivienda-vacacional-inscritos-en-el-registro) |
| INE | Códigos de los municipios (38001 Adeje, 38006 Arona, 38028 Puerto de la Cruz, 35019 San Bartolomé de Tirajana, 35013 Mogán) | Relación de municipios y sus códigos, en la web del INE |

## Herramientas

- Python (pandas, requests), SQLite, Mermaid (diagrama ER).
- HTML, CSS y JavaScript para la web; Google Fonts (Schibsted Grotesk); Vercel para publicarla.
- Herramientas de IA como apoyo para escribir código (*vibe coding*), revisado por el equipo.
